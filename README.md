# AgriLink Uganda 🌱

> Connecting smallholder farmers in Western Uganda directly to buyers.

> Proposed project by Campus Developers Collective KIU-WC

### The Problem
Farmers in Ishaka/Bushenyi sell through middlemen and lose 40% of profit. No direct market price information.

### The Solution (Proposed MVP)
A simple platform where:
1. Farmer posts crop, quantity, price via phone
2. Buyer sees nearby produce
3. Direct call/chat connection

We are starting with a simple database + SMS/USSD concept that works on low-end phones.

### 🎯 Planned Features (MVP)
- Farmer & Buyer registration
- Post harvest listings
- Search by crop & location
- Price tracking dashboard
- Offline support with Access / lightweight DB for pilot

### 🛠️ Proposed Tech Stack
- **Pilot Version:** Visual Basic .NET + Microsoft Access (for Ishaka market test)
- **Next Version:** Web + Mobile (to be decided with community)
- **Planning Partner:** Claude for requirement gathering and user flow design
